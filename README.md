# AI营销工作台

A desktop-first interactive MVP for a creative intelligence platform, built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Product flow

Brief → Signal Radar → Trend Deep Dive → Brand Opportunity → Creative Routes → AI Critic → Campaign Builder → Content Studio

All data is local mock JSON. The code structure leaves explicit UI integration points for OpenAI Agent API, web search, social connectors, image generation and PostgreSQL/Supabase.
